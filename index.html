    Exercise 11.1 — Vector-Valued Functions (Solutions)

    A vector-valued function r(t) = x(t) î + y(t) ĵ (in 2D) or r(t) = x(t) î + y(t) ĵ + z(t) k̂ (in 3D) gives the position of a moving point at time t. Here is every question of Exercise 11.1 solved.

    Q1. Give two real-life examples where vector-valued functions are necessary.

    Example 1 — A satellite in orbit. A satellite moving around the Earth in a circular orbit has the vector-valued function

    r(t) = R cos(wt) î + R sin(wt) ĵ + 0 k̂

    where R is the radius of the orbit and w is the angular velocity.

    Example 2 — A thrown ball. If a ball is thrown at an angle θ with initial velocity V0, its position is

    r(t) = (V0 cos θ · t) î + (V0 sin θ · t − ½ g t2) ĵ

    Q2. Construct a vector function for a particle moving in a circle.

    The position vector r(t) in 2D is r(t) = x(t) î + y(t) ĵ. For a particle moving in a circle with angular velocity w, radius r, centred at the origin:

    x(t) = r cos(wt),   y(t) = r sin(wt)
    Position vectorr(t) = r cos(wt) î + r sin(wt) ĵ

    Q3. Write a vector function for a car moving along a parabolic path.

    The position vector in 2D is r(t) = x(t) î + y(t) ĵ. If a car moves along the standard vertical parabolic path y = x2, take x(t) = t and y(t) = t2.

    Position vectorr(t) = t î + t2 ĵ

    Q4. Create a 3D vector function for a drone flying upward in a spiral.

    The position vector in 3D is r(t) = x(t) î + y(t) ĵ + z(t) k̂. The drone moves in a circle horizontally while climbing upward, so x(t) = R cos(wt), y(t) = R sin(wt), z(t) = bt — where R is the radius of the circle, w is the angular velocity, b is the vertical climb rate and t is time.

    Position vectorr(t) = R cos(wt) î + R sin(wt) ĵ + bt k̂

    Q5. Given x(t) = t2 + 1, y(t) = √t, construct r(t).

    Write r(t) = x(t) î + y(t) ĵ and substitute the components:

    Answerr(t) = (t2 + 1) î + √t ĵ

    Q6. Given x(t) = 1t + 4, y(t) = ln √t, z(t) = sec−1(t), construct r(t).

    Write r(t) = x(t) î + y(t) ĵ + z(t) k̂ and substitute the components:

    Answerr(t) = 1t + 4 î + ln √t ĵ + sec−1(t) k̂

    Q7(i). Find the domain and range of r(t) = √t î + ln t ĵ.

    Domain. The domain is the set of all t for which both components are defined: x = √t needs t ≥ 0, and y = ln t needs t > 0. Taking the common values:

    Domain(0, ∞)

    Range. From x = √t with t > 0, we get x2 = t with x > 0. Then y = ln t = ln x2 = 2 ln x.

    Range{ (x, y) : y = 2 ln x, x > 0 }

    Q7(ii). Find the domain and range of r(t) = cos t î + sin t ĵ.

    Domain. Both x = cos t and y = sin t are defined for every real t:

    DomainR (all real numbers)

    Range. Add the squares of the components: x2 + y2 = cos2 t + sin2 t = 1.

    Range{ (x, y) : x2 + y2 = 1 } — the unit circle
    Functions · FSc Maths

    Domain of ex — Explained with Graph

    One of the most-asked FSc questions: for which values of x is ex defined?

    Step 1 — What the function means

    ex means the constant e ≈ 2.718 raised to the power x. A positive base can be raised to any real power — positive, negative, zero, or fractional.

    Step 2 — Check the special cases

    e0 = 1,   e1 = e ≈ 2.718,   e−1 = 1/e ≈ 0.368,   e1/2 = √e ≈ 1.649

    Every real exponent gives a valid, positive answer — there is no value of x that breaks the function (no division by zero, no square root of a negative, no logarithm involved).

    Step 3 — State the domain and range

    DomainAll real numbers: (−∞, ∞), i.e. x ∈ R
    Range(0, ∞) — ex is always positive; it approaches 0 as x → −∞ but never reaches it, and grows without bound as x → ∞.
    BS / University · Linear Algebra

    Linear Algebra — Systems, Vector Spaces & Eigenvalues

    Linear algebra is the maths of vectors, matrices and linear equations — the backbone of BS mathematics, physics, computer science and data science.

    1 · Solving a system of linear equations

    Solve: 2x + y = 5 and x − y = 1. Reasoning: the y-terms cancel if we add the equations (elimination).

    Adding: 3x = 6  ⇒  x = 2.   Then 2 − y = 1  ⇒  y = 1.
    Answer — check: 2(2)+1 = 5 ✓ and 2−1 = 1 ✓x = 2,   y = 1

    2 · Determinant and inverse of a 2×2 matrix

    For A = [[a, b], [c, d]], det A = ad − bc, and if det A ≠ 0 then A−1 = (1/det A) [[d, −b], [−c, a]]. Example: A = [[4, 7], [2, 6]]:

    det A = (4)(6) − (7)(2) = 24 − 14 = 10
    InverseA−1 = (1/10) [[6, −7], [−2, 4]] — check: A·A−1 = I ✓

    3 · Vector spaces and linear independence

    A vector space is a set of vectors closed under addition and scalar multiplication (R², R³ are the standard examples; dim R³ = 3). Vectors are linearly independent if none is a combination of the others. Example: (1, 2) and (2, 4) are dependent, because (2, 4) = 2 × (1, 2). But (1, 0) and (0, 1) are independent — they form a basis of R².

    4 · Eigenvalues and eigenvectors (fully worked)

    An eigenvector of A satisfies Av = λv: the matrix only stretches it, by the factor λ (the eigenvalue). Take A = [[2, 1], [1, 2]]. Eigenvalues come from det(A − λI) = 0:

    (2 − λ)2 − 1 = λ2 − 4λ + 3 = (λ − 1)(λ − 3) = 0  ⇒  λ = 1 or λ = 3

    For λ = 3: (A − 3I)v = 0 gives −x + y = 0, so y = x → eigenvector (1, 1). Check: A(1, 1) = (3, 3) = 3(1, 1) ✓. For λ = 1: x + y = 0 → eigenvector (1, −1). Check: A(1, −1) = (1, −1) = 1(1, −1) ✓.

    Answerλ = 3 with eigenvector (1, 1);   λ = 1 with eigenvector (1, −1)

    Calculus — Limits, Derivatives & Integrals

    Calculus studies change (differentiation) and accumulation (integration). Here are the core ideas, each with a checked example.

    1 · Limits

    A limit asks what value f(x) approaches as x approaches a point — even if the function is not defined there. Standard results: limx→0 (sin x)/x = 1 and limx→0 (ex − 1)/x = 1.

    limx→2 (x2 − 4)/(x − 2) = limx→2 (x + 2) = 4   (factorise and cancel x − 2)

    2 · Derivatives — the rules

    Power: d/dx (xn) = n·xn−1  ·  Product: (uv)′ = u′v + uv′  ·  Chain: d/dx f(g(x)) = f′(g(x))·g′(x) d/dx (sin x) = cos x  ·  d/dx (cos x) = −sin x  ·  d/dx (ex) = ex  ·  d/dx (ln x) = 1/x

    Chain rule example: d/dx sin(x2) = cos(x2) × 2x = 2x cos(x2) — differentiate the outer function, then multiply by the derivative of the inside.

    3 · Application — maximum and minimum (fully worked)

    For f(x) = x3 − 3x: f′(x) = 3x2 − 3 = 0 gives stationary points x = ±1. Second derivative f″(x) = 6x:

    At x = 1: f″(1) = 6 > 0 → minimum, f(1) = 1 − 3 = −2.   At x = −1: f″(−1) = −6 < 0 → maximum, f(−1) = −1 + 3 = 2.
    AnswerMaximum value 2 at x = −1;   minimum value −2 at x = 1

    ∫ xn dx = xn+1/(n+1) + C  ·  ∫ ex dx = ex + C  ·  ∫ (1/x) dx = ln|x| + C  ·  ∫ cos x dx = sin x + C

    By parts (∫u dv = uv − ∫v du), with u = x, dv = ex dx:

    ∫ x·ex dx = x·ex − ∫ ex dx = ex(x − 1) + C   (check by differentiating: ex(x−1) + ex = x·ex ✓)

    Definite integral (area under y = x² from 0 to 1):

    BS / University · Abstract Algebra

    Group Theory — Groups, Subgroups & Lagrange's Theorem

    Group theory studies symmetry and structure. A group is a set G with an operation ∗ satisfying four axioms.

    1 · The four group axioms

    (i) Closure: a ∗ b ∈ G for all a, b. (ii) Associativity: (a ∗ b) ∗ c = a ∗ (b ∗ c). (iii) Identity: some e ∈ G with a ∗ e = a. (iv) Inverses: every a has an a−1 with a ∗ a−1 = e. If also a ∗ b = b ∗ a, the group is abelian.

    Example: (Z, +) — the integers under addition — is an abelian group: identity 0, inverse of a is −a. Non-example: (N, +) is not a group, because natural numbers have no additive inverses (there is no −3 in N).

    2 · A finite group — Z₄ under addition mod 4

    In (Z₄, +₄) = {0, 1, 2, 3}, all answers are taken mod 4. The order of an element is the smallest positive n with n·a = 0:

    ord(1) = 4  (1, 2, 3, 0)  ·  ord(2) = 2  (2 + 2 = 4 ≡ 0)  ·  ord(3) = 4  (3, 2, 1, 0)  ·  ord(0) = 1

    Since 1 and 3 each generate the whole group, Z₄ is a cyclic group. Another cyclic group: {1, −1, i, −i} under multiplication is generated by i, because i¹ = i, i² = −1, i³ = −i, i⁴ = 1.

    3 · Subgroups and Lagrange's theorem

    A subgroup H is a subset that is itself a group under the same operation — e.g. the even integers 2Z inside (Z, +), and {0, 2} inside Z₄ (check: 2 + 2 = 0 mod 4 ✓). Lagrange's theorem: the order of a subgroup always divides the order of the group. So a group of order 6 can only have subgroups of order 1, 2, 3 or 6 — never 4 or 5. A group whose order is prime (e.g. 5) has no proper subgroups at all except {e}, and must be cyclic.

    Key fact|H| divides |G| — and the order of every element divides |G| too

    Ch 1 · Number Systems — formulas

    Complex number z = a + bi (a real part, b imaginary part), i² = −1, i³ = −i, i⁴ = 1. Conjugate z̄ = a − bi. Modulus |z| = √(a² + b²). z·z̄ = a² + b². Argand diagram: z is the point (a, b).

    Example: (2 + 3i) + (1 − i) = 3 + 2i  ·  (2 + 3i)(2 − 3i) = 4 + 9 = 13
    Solved exampleSimplify (3 + 2i)(1 − i): = 3 − 3i + 2i − 2i² = 3 − i + 2 = 5 − i ✓ (using i² = −1)

    Ch 2 · Sets, Functions & Groups — formulas

    A ∪ B = in either set; A ∩ B = in both; A − B = in A only; (A ∪ B)′ = A′ ∩ B′ and (A ∩ B)′ = A′ ∪ B′ (De Morgan). f: A → B is a function if every input has exactly one output. f is injective if different inputs give different outputs.

    n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
    Solved examplen(A) = 20, n(B) = 15, n(A ∩ B) = 5 ⇒ n(A ∪ B) = 20 + 15 − 5 = 30 ✓

    Ch 4 · Quadratic Equations — formulas

    For ax² + bx + c = 0: roots α, β satisfy α + β = −b/a, αβ = c/a. Nature from D = b² − 4ac. Equation with roots α, β: x² − (α + β)x + αβ = 0. Remainder theorem: remainder on dividing by (x − a) is f(a).

    Roots 2 and −3 ⇒ x² − (2 − 3)x + (2)(−3) = x² + x − 6 = 0
    Solved exampleCheck: (x − 2)(x + 3) = x² + x − 6 ✓, and D = 1 + 24 = 25 > 0, so roots are real and distinct ✓

    Ch 5 · Partial Fractions — method

    1) If improper, divide first. 2) Factorise the denominator. 3) Write one fraction per factor with unknown constants on top. 4) Multiply through, then substitute the roots of each factor (fastest) or compare coefficients.

    (5x − 4)/((x − 2)(x + 1)) = A/(x − 2) + B/(x + 1)
    Solved example5x − 4 = A(x + 1) + B(x − 2). x = 2 ⇒ 6 = 3A ⇒ A = 2. x = −1 ⇒ −9 = −3B ⇒ B = 3. Answer: 2/(x − 2) + 3/(x + 1). Check at x = 0: LHS −4/(−2) = 2; RHS −1 + 3 = 2 ✓

    Ch 7 · Permutations, Combinations & Probability — formulas

    ⁿPᵣ = n!/(n − r)!, ⁿCᵣ = n!/(r!(n − r)!), ⁿCᵣ = ⁿCₙ₋ᵣ. P(E) = n(E)/n(S). P(A ∪ B) = P(A) + P(B) − P(A ∩ B). Conditional: P(A|B) = P(A ∩ B)/P(B).

    Arrangements of 3 letters from 5: ⁵P₃ = 5 × 4 × 3 = 60; choices: ⁵C₃ = 10
    Solved exampleP(even number on a fair die) = 3/6 = 1/2 (evens are 2, 4, 6) ✓

    Ch 8 · Binomial Theorem & Induction — formulas

    (a + b)ⁿ = aⁿ + ⁿC₁aⁿ⁻¹b + ⁿC₂aⁿ⁻²b² + … + bⁿ. General term Tᵣ₊₁ = ⁿCᵣ aⁿ⁻ʳ bʳ. Number of terms = n + 1. For even n there is one middle term; for odd n, two.

    (1 + x)⁴ = 1 + 4x + 6x² + 4x³ + x⁴
    Solved exampleTerm independent of x in (x + 1/x)⁶: Tᵣ₊₁ = ⁶Cᵣ x⁶⁻ʳ x⁻ʳ = ⁶Cᵣ x⁶⁻²ʳ. Set 6 − 2r = 0 ⇒ r = 3, term = ⁶C₃ = 20 ✓. Induction example: 1 + 2 + … + n = n(n+1)/2 — true for n = 1 (1 = 1), and adding (k+1) to k(k+1)/2 gives (k+1)(k+2)/2 ✓

    Ch 1 · Functions & Limits — formulas

    Standard limits (x → 0, radians): (sin x)/x → 1, (tan x)/x → 1, (eˣ − 1)/x → 1, (aˣ − 1)/x → ln a, ln(1 + x)/x → 1. Limit laws: limit of a sum/product/quotient is the sum/product/quotient of the limits (quotient needs a non-zero denominator limit).

    limₓ→₁ (x² − 1)/(x − 1) = limₓ→₁ (x + 1) = 2
    Solved examplelimₓ→₀ (sin 5x)/(sin 3x) = lim [ (sin 5x)/(5x) × (3x)/(sin 3x) × 5/3 ] = 1 × 1 × 5/3 = 5/3 ✓

    Ch 2 · Differentiation — formulas

    From first principles: f′(x) = limₕ→₀ [f(x + h) − f(x)]/h. Rules: power, product, quotient, chain. d/dx tan x = sec²x; d/dx sin⁻¹x = 1/√(1 − x²); d/dx aˣ = aˣ ln a. Implicit: differentiate both sides w.r.t. x, treating y as a function of x.

    d/dx [x·eˣ] = 1·eˣ + x·eˣ = eˣ(1 + x)  (product rule)
    Solved exampleImplicit: x² + y² = 25 ⇒ 2x + 2y·y′ = 0 ⇒ y′ = −x/y. At (3, 4): slope = −3/4 ✓

    Ch 3 · Integration — formulas

    ∫ tan x dx = ln|sec x| + C; ∫ 1/(1 + x²) dx = tan⁻¹x + C; ∫ 1/√(1 − x²) dx = sin⁻¹x + C. Substitution: let u = the inside function. By parts: choose u by LIATE (Log, Inverse, Algebraic, Trig, Exponential).

    ∫ 2x/(1 + x²) dx — let u = 1 + x², du = 2x dx — = ln|1 + x²| + C
    Solved exampleArea under y = x² from 0 to 2: ∫₀² x² dx = [x³/3]₀² = 8/3 ✓. Check the substitution example by differentiating: d/dx ln(1 + x²) = 2x/(1 + x²) ✓

    Ch 5 · Linear Programming — method

    1) Name the variables. 2) Write the constraints as inequalities (plus x, y ≥ 0). 3) Graph them and mark the feasible region. 4) List the corner points. 5) Evaluate the objective at every corner — the largest/smallest is the answer. An unbounded region may have no maximum.

    Minimise C = 2x + 3y with x + y ≥ 4, x, y ≥ 0: corners (4, 0) → 8 and (0, 4) → 12
    Solved exampleMinimum cost C = 8 at (4, 0) ✓. Full maximisation example with two binding constraints is in the Linear Programming card in the library below.

    Number Systems & Complex Numbers

    Real numbers: closure, commutative, associative, distributive laws and order axioms. Complex number z = a + bi, i² = −1, conjugate z̄ = a − bi, modulus |z| = √(a² + b²), z·z̄ = |z|².

    (3 + 2i)(1 − i) = 3 − 3i + 2i − 2i² = 5 − i  ·  |3 + 4i| = 5
    Solved exampleFor z = 3 + 4i: z̄ = 3 − 4i and z·z̄ = 9 + 16 = 25 = |z|² ✓
    FSc Part 1 · Ch 2

    Sets, Functions & Groups

    Union A ∪ B, intersection A ∩ B, difference A − B, complement A′. De Morgan: (A ∪ B)′ = A′ ∩ B′. A function gives one output per input; injective = one-to-one, surjective = onto, bijective = both. Group axioms: closure, associativity, identity, inverses.

    A = {1,2,3}, B = {2,3,4} ⇒ A ∪ B = {1,2,3,4}, A ∩ B = {2,3}
    Solved examplef(x) = 2x + 1 ⇒ f(3) = 7, and f is bijective on R with inverse f⁻¹(x) = (x − 1)/2. Check: f(3)=7, f⁻¹(7)=3 ✓
    FSc Part 1 · Ch 4

    Quadratic Equations

    ax² + bx + c = 0 (a ≠ 0). Formula x = (−b ± √(b² − 4ac)) / 2a. Discriminant D = b² − 4ac: D > 0 two distinct real roots, D = 0 equal roots, D < 0 no real roots. Sum of roots = −b/a, product = c/a.

    x² − 3x − 10 = (x − 5)(x + 2) = 0 ⇒ x = 5 or −2
    Solved exampleCheck: sum 5 + (−2) = 3 = −b/a ✓ and product 5 × (−2) = −10 = c/a ✓
    FSc Part 1 · Ch 5

    Partial Fractions

    Split a proper rational function into simpler fractions: one fraction for each factor — A/(x − a) for distinct linear factors, A/(x − a) + B/(x − a)² for repeated factors, (Ax + B)/(quadratic) for irreducible quadratics. Find constants by substituting values or comparing coefficients.

    1/((x − 1)(x + 2)) = A/(x − 1) + B/(x + 2)
    Solved example1 = A(x + 2) + B(x − 1). x = 1 ⇒ A = 1/3; x = −2 ⇒ B = −1/3. So the split is (1/3)[1/(x − 1) − 1/(x + 2)] ✓
    FSc Part 1 · Ch 7

    Permutations, Combinations & Probability

    ⁿPᵣ = n!/(n − r)! (order matters), ⁿCᵣ = n!/(r!(n − r)!) (order does not matter), n! = n(n − 1)…1. P(E) = favourable ÷ total. Mutually exclusive: P(A or B) = P(A) + P(B). Independent: P(A and B) = P(A)·P(B).

    ⁵P₂ = 5 × 4 = 20  ·  ⁵C₂ = 10  ·  ⁶C₂ = 15
    Solved exampleA committee of 2 from 6 students: ⁶C₂ = 6!/(2!·4!) = 15 ways. P(rolling a 6) = 1/6.
    FSc Part 1 · Ch 8

    Binomial Theorem & Induction

    (x + 2)³ = x³ + 6x² + 12x + 8
    Solved exampleCoefficient of x² in (1 + x)⁵ is ⁵C₂ = 10, so the term is 10x². Check (x+2)³ at x=1: 27 = 1+6+12+8 ✓
    FSc Part 1 · Ch 11–14

    Trig Graphs, Inverse Trig & Trig Equations

    Functions & Limits

    limₓ→₂ (x² − 4)/(x − 2) = limₓ→₂ (x + 2) = 4
    Solved examplelimₓ→₀ (sin 3x)/x = 3 × lim (sin 3x)/(3x) = 3 × 1 = 3 ✓
    FSc Part 2 · Ch 2

    Differentiation

    d/dx xⁿ = n·xⁿ⁻¹; product (uv)′ = u′v + uv′; quotient (u/v)′ = (u′v − uv′)/v²; chain rule: differentiate outside × derivative of inside. d/dx sin x = cos x, d/dx eˣ = eˣ, d/dx ln x = 1/x. f′(x) = 0 at stationary points; f″ > 0 minimum, f″ < 0 maximum.

    Solved examplef(x) = x³ − 3x: f′ = 3x² − 3 = 0 at x = ±1; max 2 at x = −1, min −2 at x = 1 (full working in the Calculus lesson) ✓

    Integration

    FSc Part 2 · Ch 4

    Analytic Geometry — Straight Line

    Slope m = (y₂ − y₁)/(x₂ − x₁); line y = mx + c; point-slope y − y₁ = m(x − x₁). Parallel lines: m₁ = m₂; perpendicular: m₁·m₂ = −1. Distance from (x₁, y₁) to ax + by + c = 0 is |ax₁ + by₁ + c| / √(a² + b²).

    Qualitative Reasoning — An Introduction (Lesson & Notes)

    Qualitative Reasoning (QR) is the area of Artificial Intelligence that reasons about the continuous physical world — quantity, space and time — with very little information: no exact numbers and no differential equations, just directions of change, landmarks and common sense. These notes follow the introduction lecture by Muhammad Fadlisyah (PMA Group, Informatics Department, University of Oslo, 2009); the complete notes are free to download below as a MathsGuru PDF, with the worked examples and the end-of-lecture quiz.

    1 · The basic idea — reasoning with very little information

    People draw useful and subtle conclusions about the physical world without differential equations — and scientists and engineers reason the same way when they first understand a problem, set up more formal methods, and interpret the results of quantitative calculations and simulations. The fact is that our knowledge is almost always incomplete, so QR creates representations for the continuous aspects of the world (quantity, space, time) that support reliable reasoning with the little knowledge we have. QR is focused on scientific and engineering domains.

    Quantitative approach: physical system → differential equations → continuous functions → actual behaviour Qualitative approach: physical system → qualitative model → qualitative behaviour

    2 · Example — boiling water

    What can happen when we leave a kettle on a stove unattended for an hour? The traditional quantitative approach describes the system with differential equations (ODEs) and solves them analytically or numerically — but first it needs the temperature of the water, the temperature of the stove, the rate of change of the water temperature, the water volume, the boiling point, and all the initial conditions.

    The common-sense (qualitative) approach needs none of those numbers: the water gets hotter, reaches its boiling point, boils and turns to steam, the level falls — and left long enough, the kettle boils dry. QR formalises exactly this: reasoning from the direction of change and a few landmark values such as the boiling point.

    3 · Example — the Challenger disaster

    On 28 January 1986 the Space Shuttle Challenger broke apart 73 seconds into its flight. All seven crew members died, and the shuttle programme had 32 months of no activity. The shuttle consisted of an orbiter, an external tank and two Solid Rocket Boosters (SRBs); an O-ring seal in the right SRB failed at liftoff, and the breach in the joint let a flare reach the outside. The SRBs were built by Morton Thiokol, Inc (MTI).

    Before the launch, the forecast for 28 January predicted an unusually cold morning, with temperature close to −1 °C — the minimum temperature permitted for launch. The low temperature worried MTI's engineers: what would it do to the resilience of the rubber O-rings? From observations since January 1985, post-flight inspections had found that hot combustion gases had blown by the joints, worst at the lowest temperature seen, 12 °C — so low temperature indeed caused significantly more hot-gas blow-by. The engineers' reasoning was purely qualitative — colder → less resilient O-rings → more blow-by — and they recommended not launching. NASA was not happy; MTI's management reversed the recommendation — and the result was the disaster. It remains the classic case for why qualitative reasoning about a system matters, even before any equation is solved.

    4 · Qualitative representations — the overview

    There is no single, universal “right” or “best” qualitative representation — there is a spectrum of choices, each with its own advantages and disadvantages, but all provide notations for describing and reasoning about continuous properties of the physical world. The four basic representations are quantity, equations, ontology and behaviour. Two key issues run through all of them:

    Resolution — the level of information detail in a representation (low vs high). One QR goal: find how little information suffices to draw useful conclusions.

    Compositionality — the ability to combine representations of different aspects of a phenomenon or system into a representation of the whole. One QR goal: to formalise the modelling process itself.

    5 · Representing quantity

    Status abstraction — the lowest-resolution representation of a continuous value: “normal” / “not normal”, “working” / “not working”.

    Sign algebra — quantities are just +, − or 0, and their derivatives are “increasing”, “decreasing” or “constant”. Used for reasoning about dynamics.

    Finite algebra — observations are naturally categorised into a finite set of labels: “very small”, “small”, “normal”, “large”, “very large” (using fuzzy logic).

    Quantity space — the set of statements about a value, using inequalities, defined by two kinds of comparison points: limit points and landmark values. Example: the temperature of water in a kettle on a stove is described against the temperature of the stove, and its freezing and boiling points.

    Intervals — a well-known variable-resolution representation for numerical values, e.g. [0, 1]: a quantity space gives partial information as a set of intervals.

    Orders of magnitude — one number is so large compared to another that the smaller may safely be ignored: the effect of evaporation on the level of a lake may be ignored if the dam holding it has burst. This avoids ambiguities and simplifies models.

    6 · Representing equations (mathematical relationships)

    Confluences are equations constructed from the basic arithmetic operations but using only sign values — for example Newton's second law as f = m [*] a. Confluences are solved by propagation of constraints, using generate-and-test when unresolvable simultaneities occur.

    Sign addition: + [+] + = + · 0 [+] − = − · + [+] − = ?   |   Sign multiplication: + [*] − = − · 0 [*] x = 0 · − [*] − = +

    Monotonic functions are one of the weakest statements that can be made about a relationship: M+(force, acceleration) says force depends only on acceleration, and the function relating them is increasing — when one increases, the other tends to increase, by an unspecified amount.

    7 · Ontology — how to carve up the world

    Ontology concerns how to carve up the world: what kinds of things there are, and what sorts of relationships can hold between them. It is central to qualitative physics, because one of its main goals is formalising the art of building models of physical systems.

    Device ontology — inspired by network theory and system dynamics (especially electronics): a system is a collection of devices which have ports for interaction; a device's behaviour is given by internal laws, decomposed into distinct states or operating regions. (+) Fixed topology, so computation is efficient; closely related to accepted engineering standards. (−) No guidance for constructing the network model; many phenomena do not fit neatly.

    Process ontology — people often describe changes in the physical world in terms of processes (motion, liquid flow, boiling). (+) Intuitively appealing for many domains; provides a simple notion of causality by distinguishing independent from dependent variables; explicit modelling assumptions. (−) Not compatible in some domains; requires more inference and manipulation.

    Substance ontology — for reasoning about liquids, in two forms: the piece-of-stuff ontology and the contained-stuff ontology.

    “No ontology” — use differential equations as the basis to derive the structure of the system. (+) Can be applied to all domains. (−) The compositionality issue is not considered.

    8 · Representing behaviour

    A qualitative state is a set of propositions that characterise a qualitatively distinct behaviour of a system — one qualitative state can abstractly represent an infinite number of quantitative states. Behaviour is a sequence of qualitative states occurring over a particular span of time.

    Histories — a history is a piece of space-time containing properties: a collection of episodes, which serve as the spatiotemporal scope for the facts associated with them. A history describes a specific behaviour of an object, and each episode is an occurrence of one of a finite set of abstract qualitative states.

    Envisionments — an envisionment is a graph formed by the collection of qualitative states of a system and the transitions between them; producing one (envisioning) is qualitative simulation. An attainable envisionment starts from a given initial state; a total envisionment starts from all possible states.

    Worked example — the mass–spring systemFor a block on a spring, take x = position (x = 0 at equilibrium, + to the right, − to the left), v = velocity, a = acceleration, f = force, with m and k positive constants. The confluences f = m [*] a (Newton's second law) and f = −k [*] x (Hooke's law) generate just 9 qualitative states — the sign patterns of (x, v, a, f) — and the transition graph between them is exactly the spring's endless oscillation cycle.

    9 · Where qualitative reasoning is used

    Monitoring & diagnosis — DEDALE maps numerical measurements into order-of-magnitude ranges to diagnose electronic circuits coming off assembly lines; NASA's FaultFinder uses low-resolution qualitative information in a causal model to detect engine trouble in commercial aircraft and explain it to the pilot. Design — failure modes and effects analysis (FMEA) perturbs a qualitative model of a chemical-plant design with various faults, then uses qualitative simulation to find the possible indirect consequences of each. Tutoring systems — qualitative representations power learning environments for electronics, power-generation plant operation and ecology. (Representing time, space and shape, and the reasoning techniques themselves, are the advanced topics; current research integrates qualitative and quantitative approaches — often called semi-quantitative reasoning.)

    The lecture quiz · Qualitative arithmetic. If [x] = +, [y] = −, and [x] + [y] = [z] — what is [z]?

    Show answer & explanation

    Answer: [z] cannot be determined — it can be +, 0 or −. In sign algebra, + [+] − = “?”: adding a positive and a negative quantity, the sign of the result depends on their magnitudes, and magnitudes are exactly what the sign representation leaves out. It is the one genuinely ambiguous cell of the qualitative addition table — the honest price of reasoning with very little information.
